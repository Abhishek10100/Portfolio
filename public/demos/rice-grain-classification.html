Rice Grain Image Classification

Multi-class image classification of 5 rice varieties (Karacadag, Basmati, Jasmine, Arborio, Ipsala), benchmarking 7 CNN architectures via transfer learning to find the strongest model.

Key findings

  • Evaluated on 3,750 held-out test images across 5 balanced classes (~750 images each).
  • Test accuracy by architecture: VGG-16 91.8%, ResNet 99.17%, DenseNet 99.23%, Inception 99.73%, Xception 99.95%, MobileNet 99.97% (best overall).
  • VGG19 failed to converge on this task, scoring only 19.5% — a useful negative result showing not every pretrained backbone transfers well without more tuning.
  • MobileNet's near-perfect accuracy at a fraction of the parameter count makes it the practical choice for a lightweight, deployable classifier.
