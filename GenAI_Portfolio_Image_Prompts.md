# GenAI Portfolio — Image Generation Prompt Pack

## Global Visual Direction

Use this as the **base instruction for every image**:

> Create a premium, modern visual asset for a personal GenAI Engineer portfolio website. Maintain the exact visual identity of the supplied character reference `Character.png`: same face, hairstyle, beard, skin tone, proportions, clothing style, and recognizable facial features. Use a polished 3D emoji/avatar aesthetic with soft realistic materials, expressive but professional proportions, clean studio-quality rendering, subtle depth of field, soft ambient lighting, and sophisticated editorial composition.
>
> The website is **light-mode first**, minimal, elegant, spacious, and technology-forward. Use an off-white / warm-white environment, soft neutral gray surfaces, subtle glassmorphism, restrained blue-violet AI accents, and generous negative space. Avoid visual clutter, cyberpunk aesthetics, neon overload, excessive gradients, stock-photo realism, and generic "AI robot" imagery.
>
> The visual language should communicate **Generative AI, LLMs, RAG, AI agents, document intelligence, semantic search, and production AI engineering**.
>
> Important: do not render long paragraphs, UI copy, logos, brand names, or unnecessary text inside the image. Any labels should be minimal and easy to replace in the website UI.
>
> Compose every asset so it can be animated later with React, Tailwind CSS and Framer Motion: clear foreground/background separation, isolated visual elements, predictable spatial hierarchy, and enough negative space for overlays.

# Animation Strategy

Do not treat these as ordinary static images.

For the final website, animate the generated assets with Framer Motion:

- floating objects → subtle `y` movement
- workflow connections → animated path/reveal
- cards → staggered entrance
- nodes → opacity/scale pulses
- character → extremely subtle idle movement
- project visuals → parallax layers
- metrics → count-up animation in HTML, not baked into images
- light/dark theme → CSS/UI transformation rather than separate raster assets where possible

The generated images should provide the **visual foundation**, while React, Tailwind CSS 4.3, SVG and Framer Motion provide the interaction and animation.
